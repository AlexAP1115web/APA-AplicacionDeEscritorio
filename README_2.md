# TaskDesk — Gestor de Tareas Personales

Aplicación de escritorio (Python + Tkinter), independiente y autocontenida: no depende
de ningún otro sistema, base de datos externa ni conexión a internet.

## Requisitos
- Python 3.8 o superior (Tkinter viene incluido con Python en Windows/macOS/la mayoría de
  distribuciones Linux).

## Cómo ejecutarla
```bash
python taskdesk.py
```

## Funciones
- Agregar tareas con una prioridad (Alta, Media, Baja).
- Marcar una tarea como completada con doble clic sobre ella.
- Eliminar la tarea seleccionada de la lista.
- Guardado automático de todas las tareas en `tareas.json`, en la misma carpeta del
  programa, con fecha y hora de creación.
- Resumen en vivo de tareas pendientes y completadas.
